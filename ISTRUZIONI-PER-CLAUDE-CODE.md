# Istruzioni per Claude Code

Questa cartella contiene il design system della campagna "Vivi Motta a Natale" e gli esempi impaginati.

- `PRODUCT.md`: contesto della campagna.
- `design-system/`: regole (`design-system.md`, `componente-*.md`), token (`tokens.json`, `tokens.css`) e le 16 tessere SVG.
- `pagine/`: gli esempi in HTML, da aprire nel browser (`pagine/index.html`).
- `reference/`: le immagini di riferimento scelte dal cliente.
- `assets/`: il logo.

## Cosa chiedere

Il cliente trova la tipografia e i testi banali, "da AI". Obiettivo: rendere il design system unico e riconoscibile usando Impeccable, mantenendo:
- l'idea del mosaico di tessere geometriche e degli archi (portici);
- i colori presi dal logo;
- Zenzerino secondario;
- formati Instagram (1080×1350 e 1080×1920) e font disponibili in Canva.

Alla fine aggiorna sia i file in `design-system/` sia le pagine in `pagine/`, e scrivi in `MODIFICHE.md` cosa hai cambiato e perché.
