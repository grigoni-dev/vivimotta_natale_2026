# Marchio "Motta Natalè"

"Motta" sopra, "✦ Natalè" sotto in corsivo; l'accento della "è" ha il colore della stella. File vettoriali con il testo già convertito in tracciati: si usano in Figma (dove sono già componenti) o in qualunque altro programma, senza bisogno del font.

| File | Fondo |
|---|---|
| `marchio-panna-ocra.svg` | verde-loggia |
| `marchio-panna.svg` | rosso |
| `marchio-verde.svg` | rosa, azzurro |
| `marchio-verde-rosso.svg` | panna |
| `stella.svg` | la stella da sola, simbolo della campagna (ocra) |
| `profilo-motta-natale.png` | immagine del profilo Instagram, 1080×1080 |

Origine: lettere tratte da Bodoni Moda (Owen Earl, licenza SIL Open Font License 1.1, Google Fonts). "Motta" è in ExtraBold (peso 800), "Natalè" in Medium Italic (peso 500); entrambi dai file Bodoni Moda 11pt in `design-system/font/`. I file si rigenerano con `python3 genera.py` (serve `pip install fonttools uharfbuzz`). La stella a quattro punte è disegnata a mano. La licenza OFL permette di usare le lettere nei loghi senza costi.
